About this project

Led an independent March–May 2025 project combining a React Native Android/iOS app, Odoo 17 and Pavo OMS APIs. Odoo acts as the resilient bridge: mobile orders land in Odoo first and can continue operating during OMS downtime, then synchronize to Pavo when service is restored.

Key features / deliverables

  • Synchronized customers, products, inventory and orders with Pavo OMS
  • Barcode scanning lets shoppers build a digital cart while moving through the store
  • Designed fallback synchronization so sales flow continues during OMS outages
  • Deployed on IONOS with Ubuntu, PostgreSQL, Nginx, SSL/Certbot, systemd, backups and domain configuration
  • Implemented GitHub Actions CI/CD
