Attendance Dashboard & Leave Gantt

TTI Testing Laboratories · 2026 · Odoo ERP

Odoo 18OWLJavaScriptPythonAttendanceAnalyticsExcel

About this project

Designed the workflow and business logic and built both the Python/Odoo backend and OWL/JavaScript frontend for an interactive attendance and leave board. It combines daily employee status, click-to-edit records, KPIs, leave insights, trend charts, filters and Excel export while remaining timezone-, schedule- and access-right aware.

Key features / deliverables

  • Present, absent, late, recurring-late and check-in/out issue KPIs with drill-down
  • Gantt-style daily grid with half-day and multi-day leave handling
  • Single-RPC data loading instead of per-cell queries for better performance
  • Timezone, resource-calendar, shift and public-holiday aware
  • Interactive charts, multi-company filters and Excel export

Also available as a NeuralBytea app

A marketplace edition is published as Attendance Leave Gantt.
