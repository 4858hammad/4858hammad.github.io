Multi-Device Biometric Attendance

TTI Testing Laboratories · 2026 · Odoo ERP

Odoo 18AttendanceBiometricHR

About this project

Extended the ZK biometric attendance integration so each employee can hold a different PIN per device, check-ins and check-outs record which device was used, and the attendance board shows per-device KPI cards and rosters. Sync windows were made configurable and punches are scoped by device.

Key features / deliverables

  • Per-device biometric PIN model with a tag widget on the employee form
  • Check-in and check-out device tracking, with per-device KPI cards and a device filter showing the full roster
  • Push, update and delete device users and view device info from Odoo
  • Configurable back-fill window per device and serialized attendance generation
  • Clear errors when the device server returns an unexpected reply
