About this project

Led the ClearPath Orthodontics Odoo implementation and worked with the functional team to translate business requirements into portal, Sales, payment, Manufacturing and Inventory workflows. Approximately 200 doctors/clinics used the portal and the operation processed around 250 orders per day.

Key features / deliverables

  • ~200 doctor/clinic portal users and ~250 daily orders
  • Advance-payment workflow before order release into manufacturing
  • BOMs, Manufacturing Orders, production stages, material consumption and inventory movements
  • Customized a generic ZK attendance connector for multi-location use, APIs, duplicate handling, work locations and time handling
  • Added employee- and department-specific attendance downloads
