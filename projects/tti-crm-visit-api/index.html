CRM Visit Sync & Fuel Cost Model

TTI Testing Laboratories · 2026 · Odoo ERP

Odoo 18REST APICRMIntegration

About this project

Built a bridge that receives field-visit, employee and vehicle data from TTI's CRM into Odoo, with bulk upserts and a dated fuel-rate history. Visit cost is calculated from distance, vehicle average and the applicable fuel rate, with the calculation method tracked on each visit.

Key features / deliverables

  • Batch upsert endpoints for visits, employees and vehicles
  • Fuel-consumption cost model: liters = distance / average km, using the rate in force on the visit date
  • Dated Fuel Rate History and a tracked 'Calculated Cost by' field
  • README, Postman collection and automated tests
