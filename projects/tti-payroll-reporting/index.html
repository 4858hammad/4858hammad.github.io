Payroll Accuracy & Salary Reporting

Payslip day-count fixes, error status, dynamic deduction columns and a grouped salary report

About this project

Reworked payroll calculation and reporting so a month that does not add up says so. Approved leave is counted correctly, rest days come from each contract's schedule, and the salary report groups by work location with deductions and allowances driven by the payslip rules instead of hard-coded columns.

Key deliverables

  • Error Status on payslips flags months whose figures do not add up
  • Compute Sheet now gives the same day-count as a batch run, and approved leave is no longer silently unpaid
  • Dynamic deduction columns matched by rule code, plus an Other Allowance column with a one-click setup
  • Salary report grouped by work location and filterable by company, with approval signature lines
  • Salary journal line names rebuilt from the payslip rule so re-running never duplicates them
