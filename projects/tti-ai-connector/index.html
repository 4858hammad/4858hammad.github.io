Claude AI Connector for Odoo

TTI Testing Laboratories · 2026 · Odoo ERP

Odoo 18MCPAISecurity

About this project

Built and deployed an MCP server module that connects Claude to TTI's Odoo 18. Managers and administrators ask questions in plain language and get clear answers on the status of the system and the company, with charts on demand. It is read-only by default and every answer respects the asking user's own access rights.

Key features / deliverables

  • Read-only by default, with results limited to what each user is already allowed to see
  • Dedicated AI Connector user group controlling who can see the menu and settings
  • Model-description tool lists key and required fields first on models with many fields
  • Covered by automated tests that run independently of the data in the database

Also available as a NeuralBytea app

A marketplace edition is published as Claude Connector for Odoo.
