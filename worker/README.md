# Portfolio chat proxy (Cloudflare Worker)

The "Ask AI" widget on the site (`assets/chat.js`) talks to this Worker. The Worker holds the Groq key, so the browser never sees it.

## Deploy (free tier is enough)

```bash
cd worker
npm i -g wrangler          # once
wrangler login
wrangler secret put GROQ_API_KEY     # paste the Groq key when asked
wrangler deploy
```

Copy the printed `https://hammad-portfolio-chat.<you>.workers.dev` URL, then in GitHub:
**Settings → Secrets and variables → Actions → Variables → New variable** `CHAT_ENDPOINT` = that URL. Re-run the Pages workflow.

## Safeguards
Origin allow-list (`ALLOWED_ORIGINS` in `wrangler.toml`), per-IP rate limit, message size limits, edge cache for repeated first questions, key-pattern redaction in replies.

## Tests
`npm test` (plain Node 18+, no dependencies).

## Knowledge
`src/knowledge.js` is generated by `python tools/build_site.py` from `portfolio_data.yaml` and `data/apps.json`. Rebuild, then redeploy the Worker after content changes.

## Direct mode (no Worker)
If `CHAT_ENDPOINT` is empty and the Actions secret `GROQ_API_KEY` (or `CHAT_KEY`) exists, the build embeds a lightly scrambled copy of the key in the page. Anyone can recover it from DevTools. Use it only with a dedicated, rate-limited key and rotate it if abused.
